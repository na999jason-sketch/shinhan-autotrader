# 신한 자동매매 v0.3 — 국내주식 코스피·코스닥

**이 패키지는 프로그램 소스 + Windows EXE 자동 빌드 구성입니다. ZIP 자체는 EXE가 아닙니다.**

> **실계좌 기능은 신한투자증권의 실제 2026년 서버·계좌에서 검증하지 못했습니다.**
> 이 프로젝트를 *실전 운용 가능한 완제품*이라고 주장하지 않습니다. 
> 주문/체결/잔고 이벤트 필드 및 현금매수가능금액 조회 API는 신한에서 받은 최신 **Interface 사양서**와 PC 환경을 대조해야 합니다.
> 실계좌 모드는 실주문을 보낼 수 있으므로 미검증 상태로 켜지 않는 것을 권장합니다.

## 구현된 기능

- **자동 종목발굴**: `stock_mst` 전 종목코드 조회 → 관리/정지/시장경보 종목 제외 → `TR_SCHART` 확정 일봉 순차 분석 → 후보별 시세 `SC` 확인. 코스피/코스닥 일반주식(ST)만 대상으로 합니다.
- **매수**: 5일선 > 20일선, 20일선 상승, 20일 평균 거래대금 30억원 이상, 20일 최고가 돌파(2.5% 이내), 전일 대비 과도한 급등 배제. 기본 예시 전략이며 실질적 수익 우위는 검증되지 않았습니다.
- **매도**: 매입단가 -6% 손절, +12% 익절, 최고가 대비 -7% 추적손절. 사용자가 GUI에서 값을 변경할 수 있습니다.
- **위험관리**: 최대 3종목, 종목당 평가금액 최대 20%, 매수당 최대 10만원(초기 안전 상한, 화면에서 언제든 변경), 하루 주문 6회 제한, 새 매수는 09:25~14:40, 매도는 09:05~15:10. 신용잔고/미체결/시세 지연·접속 오류 발생 시 차단. 미수나 신용 주문은 코드에서 수행하지 않도록 구성.
- **주문 안전성**: 주문 전 JSONL 영구 기록, 주문응답과 체결 구분, 계좌보유수량 변화 확인, 미확정 주문 존재 시 후속 주문 차단, 재시작 이후 미확정 주문 자동 재전송 차단, 동일 종목에 대한 기존 보유분 자동매도 금지.
- **PC GUI**: 자동탐색 후보/관리종목/로그, 설정 변경, 신규매수만 정지(보유분 매도 감시 계속), 전체 자동주문 긴급중지.
- **모의매매**: 실제 증권사에 연결하지 않고 합성 종목 100개로 종목선정 → 매수 → 매도 흐름을 확인. 가상 주문은 즉시 전량 체결을 가정하므로 현실적인 백테스트·체결 시뮬레이터가 아닙니다.

## 중요 미검증 및 미구현 영역

1. **실계좌 자동 주문가능금액 조회는 미구현**. 공개적으로 확인한 `SABA200QB`는 보유수량·평균단가·미체결수량을 조회하지만, 현금 100% 매수가능금액 필드가 명시되지 않았습니다. 따라서 실계좌 신규매수 전 HTS에서 직접 확인한 **당시 주문가능금액**을 화면에 입력·재확인해야 합니다. 고정 투자원금은 아닙니다. 재확인 5분 초과 또는 주문 이후에는 다시 확인해야 합니다. 입출금 자동 반영 기능은 **미구현**입니다.
2. **체결/잔고 실시간 이벤트(AA·AB·AD·AE)**: 구독 시도를 구현했고 이벤트를 받으면 잔고를 재조회합니다. 이벤트 실제 등록 성공 및 데이터 스키마는 검증되지 않았습니다. 신한 FAQ는 최초 TR 이후 해당 실시간 이벤트 사용을 권고합니다.
3. 실제 체결가 조회/정정·취소 주문/주문번호별 완전한 체결 대조는 **미구현**. `SABA200QB`의 보유수량 변화로 체결수량을 제한적으로 판단하지만, **매도 체결가격은 확정할 수 없어 매도 당시 참고가로 잠정 기록**합니다. HTS 실현손익과 일치하지 않을 수 있습니다. 동일 종목에 대해 수동 주문이 섞이면 판별이 불가능하므로 프로그램을 중지해야 합니다.
4. 주식매수 시장가 주문은 예상 체결가격을 보장하지 않습니다. 3% 수량 버퍼는 최대 손실 제한이나 최대 체결금액 보장이 아닙니다.
5. 거래소 휴장일 달력, KRX/NXT 시장별 라우팅, 자동재접속, 장 마감 후 미체결 정정·취소, 거래수수료/세금과 실제 슬리피지를 포함한 완전한 백테스트는 **미구현**입니다.
6. 시장 전 종목 일봉을 약 2초당 1건으로 **순차 조회**하므로 초기 전체 스캔은 오래 걸립니다. 서버 호출 제한을 더 엄격하게 적용해야 하면 간격을 늘리십시오. 복수의 실시간 주가 모니터링을 위한 더 효율적 체결 스트림 스캐너는 후속 개선점입니다.
7. PC 종료/전원 장애/프로그램 예외/인터넷 단절 시 자동 손절·익절은 실행되지 않습니다. 비상 정지 버튼은 기존 접수 주문을 취소하지 않습니다.
8. 이 작업 환경에서는 Windows 32비트 OCX, 신한 서버 및 윈도우 EXE를 실행할 수 없어 **실제 GUI/OCX/EXE 성공 여부를 검증하지 않았습니다**. 코어 테스트만 통과했습니다.

## 실행 준비

신한i indi 공식 안내: https://www.shinhansec.com/siw/customer-center/channel/channel_homeTrading-indi/contents.do

1. Windows PC에서 신한i indi **개인 사용계약 신청**, **주식/선물옵션용 Indi 설치·로그인**을 준비합니다.
2. 사용자 계좌가 미수·신용을 쓰지 않도록 증거금/거래환경을 별도로 확인해야 합니다.
3. 프로그램은 Windows **32비트 Python + PyQt5.QAxContainer**, 또는 그 환경으로 빌드한 32비트 EXE가 필요합니다.
4. 매매계좌번호/계좌비밀번호는 **채팅이나 GitHub에 올리지 마십시오.** 실행화면에만 입력하고 저장하지 않도록 작성했습니다.

### 별도의 Python 설치 없이 `.exe` 만들기 (GitHub Actions)

프로젝트 파일 전체를 **본인 소유 GitHub 저장소**에 올린 뒤 GitHub의 **Actions → Build Shinhan AutoTrader Win32 → Run workflow**를 실행하면 Windows 빌드 머신에서 EXE를 만듭니다. 결과는 해당 Actions 실행 페이지의 Artifacts 아래에 게시됩니다. 사용자의 Windows PC에는 Python을 따로 설치하지 않아도 됩니다. 그러나 **GitHub에서 EXE 빌드가 실제 성공했는지는 이 환경에서 확인하지 못했습니다.** 신한i indi OCX 자체는 PC에 설치해야 합니다.

### 개발환경에서 직접 실행 (Windows)

Windows용 **32비트 Python 3.11**에서 프로젝트 폴더를 열고:

```powershell
py -3.11-32 -m pip install -r requirements-build.txt
py -3.11-32 app.py
```

직접 실행 후 실계좌 연결은 소액 주문 검증과 API 사양 확인 전 사용하지 마십시오.

### 기능 확인 순서

1. 기본 선택값인 **모의매매(가상)**을 유지합니다.
2. `신한i indi 연결 / 종목조회` 버튼 → 가상 100종목 생성.
3. `자동매매 시작` → 후보 탐색, 가상 매수 및 가상 자동매도, 원장 기록을 확인합니다.
4. `발굴 후보`, `자동매매 보유분`, `실행·주문 기록` 탭을 확인합니다.
5. 실계좌 테스트는 신한 최신 사양서, 주문/체결, 현금잔고 확인을 마친 뒤 진행합니다.

## 소스 구조

| 파일 | 내용 |
|---|---|
| `engine.py` | 종목 선정·매도 판단·투자 비중·미확정 주문 영구 원장·재시작 복원 |
| `indi_client.py` | Windows 신한i indi ActiveX 시세/잔고/주문 요청 어댑터 |
| `app.py` | GUI 및 매매 순서 조정, 실계좌 주문 활성화 확인 절차 |
| `tests/` | 단위 및 오프라인 종목→매수→자동매도 전체 흐름 테스트 14건 |
| `.github/workflows/build-exe.yml` | Windows 32비트 EXE 빌드 설정 |

### 테스트

```bash
python -m unittest discover -s tests -v
```

**작성 환경 결과: 14개 통과.** 이는 신한 실제 서버, OCI/COM 객체 및 Windows GUI 테스트가 아니라 브로커 비종속 핵심 로직 테스트입니다.
