# 과거 가상 계정 엔진 보관

이 디렉터리의 `TradingEngine.cs`와 `TradingEngineTests.cs`는1.x에서 사용하던 가상 계정·체결 검증 코드입니다. 변경 이력을 보존하기 위해 이동했습니다.

**2.0 Windows EXE에 컴파일하지 않으며 현재 계좌 잔고·주문·체결·손익 화면에서 사용하지 않습니다.** 현재 빌드 파일은 루트의 `*.cs`만 포함합니다. 이 디렉터리를 재귀적으로 컴파일 대상에 추가하지 마십시오.

이전 `%LOCALAPPDATA%\ShinhanNativeTrader\paper-v2.xml`과 구형 CSV는 보존되지만2.0에서 읽거나 실계좌 정보로 변환하지 않습니다. 예전 가상 현금·주문·체결·수익을 실제 계좌 증거로 취급하지 않습니다.

실제 계좌 데이터는 현재 조회 파서, 주문 상태 저널과 보고서 코드를 사용합니다. 실행 방법과 실서버 검증 경계는 [루트 README](../../README.md)를 참조하십시오.
