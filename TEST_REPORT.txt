원인과 수정
- COM outgoing IID/DISPID/인자형을 고정값 대신 설치 typelib에서 확인한다.
  동일 UI STA에서 AxHost와 이벤트 delegate 수명을 유지하며 재연결 시 재생성한다.
  실제 설치 OCX에서 고정값이 문제 원인이었는지는 실서버 미검증이다.
- RequestData 반환 전 ReceiveData 재진입을 처리하고 콜백 중 버퍼를 복사한다.
  요청번호 대조·중복·불일치·타임아웃·파싱 오류를 독립 상태기계로 검증한다.
- 일봉 신호 가격으로 즉시 가상매수하지 않고 당일 신호+별도 최신 현재가를 요구한다.
- 스캔 완료 후 보유 감시를 유지한다. 보유는 가장 오래 대기한 종목부터 조회하고
  스캔/후보 조회에도 주기적으로 순서를 배정한다. 수신 오류 시 자동 처리를 중단한다.
- 가상현금 CSV 대신 원자적 XML 상태에 주문/체결/예약금/고점을 저장한다.
  재시작 미체결은 불명 상태로 차단하며 명시적 모의 취소만 허용한다.
- C# read-only COM allowlist 및 영구 LiveOrderPolicy, Python order/request guard로
  기존 UI 밖 직접 발주도 차단한다. 주문 필드는 추측해서 추가하지 않는다.

로컬 자동 검증

  Windows targeting pack을 이용한 정식 .NET4.8 빌드의 대체 결과는 아니다.
- C# 118 assertions 통과: 기존 전략 11 + 수신/파서 38 + 모의 엔진/전략 69.
- Python unittest 17 tests 통과: 기존 엔진/전체 사이클 14 + 실주문 잠금 3.
- Linux Mono/Xvfb UI 기능 검증 15 assertions 통과: 화면/탭/전략 입력,
  비율 단위 변환, 원금·전략 저장 및 재시작 복원. 격리된 /tmp 계정 사용,
  주문/포지션 생성 0건. Windows 검증이나 화면 외관 검증을 의미하지 않는다.
- PE 검증: I386 PE32 + CLR 32BITREQUIRED 확인.
- 로컬 Mono 실행 pointerBytes=8: Linux 런타임은 x86 프로세스 실행 증거가 아니다.
- git diff --check 통과.
