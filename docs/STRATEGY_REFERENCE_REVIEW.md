# 사용자 제공 투자전략 참고 글 검토

원문: [2026-11-12 국내주식 AI 매매일지 — 이타룩스](https://m.blog.naver.com/shinhs1126/224474746869). 사용자 요청은 전략 참고이며 이 검토에서 실행 중 전략이나 기본값을 변경하지 않았다.

## 접근과 근거

웹 검색 도구의 직접 열기는 robots 차단이었다. 같은 공개 URL을 HTTPS로 읽어 모바일 HTML200(260,433 bytes)과 데스크톱 PostView HTML200(403,764 bytes)을 확보했고 실제 본문 텍스트를 확인했다. 데스크톱 짧은 주소는 본문 프레임 HTML200이었다. 이미지 안의 차트·체결 원본은 분석하지 않았다. 원문 HTML과 전체 본문을 저장소에 재배포하지 않는다.

이 글은 저자의 거래 복기·주장과 다음 거래일 시나리오다. 증권사 체결 원장이나 재현 가능한 전체 알고리즘 명세로 취급하지 않는다.

## 글에서 확인한 전략

| 구분 | 저자가 서술한 조건 |
| --- | --- |
| 단타 자금 | 종목당200만원 고정, 최대3종목. |
| 단타 진입 | 거래대금 급증·VI 이후 당일 고점 돌파, 피보나치38.2%/50% 눌림 반등, 또는1시간봉 W-4+ 반등. 약세장 진입 억제. |
| 단타 청산 | 약1% 손절, 본절컷,0.5%/1% 분할 익절과 잔량의5분봉5선 추적. |
| 별도 종가 유형 | 장마감 진입·익일 갭 공략 설명과 당일 청산 사례가 함께 있다. 적용 세션을 별도로 정의해야 한다. |
| 별도 스윙 유형 | 일봉3/8/15/45선·거래량 감소·45선 반등.3~5영업일 보유,5% 손절.3.5%/7%에서 각각30% 청산, 잔량12% 목표. |

위 수치는 해당 글의 설명이며 이 프로그램에 대한 추천 설정이나 수익 검증 결과가 아니다. 저자가 구분한 가상 관찰 기록은 실제 체결 증거에 합치지 않는다. [원문](https://m.blog.naver.com/shinhs1126/224474746869)

글의 당일 합계는 손실로 기재돼 있다. 짧은 손절 목표와 더 큰 실제 기재 손실도 구분해야 한다. 손절 신호의 기준과 실제 주문·체결 가격, 비용·슬리피지는 같은 값이 아니다. 제목의 익절 사례나 목표 수익을 반복 가능한 성과로 일반화하지 않는다. [원문](https://m.blog.naver.com/shinhs1126/224474746869)

## 현재 코드와의 차이

현재 [Strategy.cs](../Strategy.cs)의 기본 동작은 다음과 같다.

| 항목 | 현재 구현 | 검토 시 차이 |
| --- | --- | --- |
| 분석 주기 | 일봉. 마지막 봉을 제외한 앞선 봉에서 이동평균·고점·평균 거래량 산출 | 위 단타의 분봉/시간봉을 일봉 길이만 바꿔 재현할 수 없다. |
| 진입 | 직전5일 평균이20일 평균보다 높고, 최신 봉 가격이 직전20봉 고점 돌파, 거래량은 직전20봉 평균의1.3배 이상 | 거래대금·VI·당일 저항·눌림 반등·시장 국면 선택은 별도다. |
| 배분 | 실제 가용금액·운용한도·종목별 가능금액 중 허용액의20%, 최대3보유 | 동일 종목 고정 금액과 잔여 가용금액 비율은 다르다. |
| 청산 | 평단 대비6% 손절·12% 익절,4% 상승 후 고점 대비7% 하락 추적손절 | 단계별 부분 청산이나 이동평균 이탈 방식이 없다. |
| 상태 | 실제 주문·체결 저널, 보유 고점과 당일 신호/중복 키 | 분할 청산 도입 시 단계별 실제 체결수량과 잔여 주문을 추적해야 한다. |

전체 종목 순차 일봉 스캔을 실시간 분봉 전략으로 바꾸려면 데이터 수집·봉 생성·시간 정렬·결손 복원 구조도 달라진다. 손절/익절 숫자만 덮어쓰면 원문 전략을 구현한 것이 아니다.

## 원문만으로 확정할 수 없는 부분

- 거래대금 급증과 약세장 차단의 수치·비교 기간, VI 전후 진입 허용시간.
- 피보나치 기준 고저점·기간·반등 확정식, W-4+ 파동 판정식.
- 단타 분할 비율·본절 이동 조건·분봉 확정 시점·추적 기준과 주문 재시도 규칙.
- 스윙의 거래량 감소 경계·진입 밴드 산식·영업일 계산과 오버나잇 범위.

따라서 단타·스윙을 분리한 선택 전략으로 정의하고, 빠진 수식을 먼저 확정해야 재현 가능한 구현과 검증이 가능하다. 단계별 청산은 실제 체결을 기준으로 진행하고 미체결 잔량·중복 주문을 기존 저널과 대사해야 한다. 기존 계좌·거래일·실시간 시세·잔고·현금·수량·주문 직전 검사는 전략 변경과 독립적으로 유지해야 한다.

이번 작업은 참고 내용의 대조만 수행했다. 자동 주문 전략·설정·거래대상 변경이나 실제 주문을 실행하지 않았다.
