# 미체결 매수 대기와 보유 매도 차단 수정 — 2.2.16

사용자 보고서에서 정상 접수된 미체결 매수는 잔고 조회에 없고, 다른 보유는 손절 조건과 매도가능수량이 확인됐는데도 매도 주문이 없는 상태를 확인했다. 미체결 매수는 아직 보유가 아니므로 잔고에 없는 것이 정상이다. 사용자 원본 보고서·계좌 식별자·실제 주문번호는 저장소에 포함하지 않았다.

기존 BrokerReadiness는 미체결 주문 종목이 잔고에 없으면 전체 주문 대사를 실패시켰다. 정상 접수·동일 계좌·당일·정확한 주문 식별·무체결 수량을 새 조회와 대조한 원매수에만 이 조건을 바로잡는다. 예약금은 유지하며 외부 주문·불명 접수·부분체결 수량 불일치·누락 매도는 정상 처리하지 않는다.

스케줄러는 안전하게 전송 가능한 보유 매도 조건을 아직 전송하지 않은 매수 사전검증보다 우선한다. 진행 중인 조회가 끝날 때까지 기다리며 조회 응답을 폐기하지 않는다. 전송·접수 응답 대기 중인 주문을 다시 보내지 않는다.

자동 매수 미체결은 최초 CreatedUtc부터 기본120초 후 취소를 검증한다. 전략 설정에서30~1800초로 저장 가능하며 기존 설정 파일은120초 기본값을 유지한다. 당일 자동 전략 주문과 정상 접수 근거가 있는 경우에만 새 계좌·주문 조회를 거쳐 독립 취소 주문을 준비한다. 마지막 전송 단계에서도 증권사 원주문 잔량을 확인해 부분체결만큼 취소 수량을 줄이고, 잔량0이면 취소를 보내지 않는다. 외부 수동 주문·매도 주문은 타이머 대상이 아니다.

시간초과 관리는 실주문 승인이 유지되는 기존 운영시간 안에서 실행한다. 운영 중단·로그아웃·앱 종료·기존15:20 운영 종료 후에는 취소를 새로 보내지 않는다. 따라서 종료 직전 접수된 주문의 대기시간이 운영 종료를 넘으면 이 타이머가 취소를 보장하지 않는다. 종료 시 미체결을 취소하지 않는 기존 동작과 장 운영시간은 이번 수정에서 변경하지 않았다.

취소 접수는 AwaitingConfirmation이고 취소 완료가 아니다. AA05로 확인된 수량만 원매수 CancelledQuantity에 반영하며 예약금을 해제한다. AA05가 누락되거나 주문 결과가 불명인 경우 취소를 자동 재전송하지 않는다. 조회의 미확인 정정·취소 숫자 코드를 추정하거나 행 누락만으로 취소를 확정하지 않는다. 확인 가능한 다른 종목 매도는 독립 검증한다.

무체결 전량 취소가 실제 확인된 자동 매수만 현재 매수 조건·최신 시세·잔고·현금·한도·가능수량을 새로 통과한 뒤 당일1회 추가 진입할 수 있다. 부분체결 후 취소에는 재진입을 적용하지 않는다. 추가 진입 주문도 미체결이면 같은 대기시간 후 잔량 취소 대상이지만 세 번째 진입은 하지 않는다.

업데이트·재시작으로 Unknown이 된 기존 주문은 보존된 정상 접수 근거와 계좌·당일·번호·종목·방향·수량·가격·새 요청 시각이 일치하는 조회로 기존 Working/PartiallyFilled 상태만 복구한다. 실제 개별 체결 근거가 없는 누적 부분체결을 만들어 넣지 않는다. 최초 주문시각을 보존하고 주문 승인과 과거 주문을 자동 재전송하지 않는다. 기존 전량체결 복구와 현재 평가잔고수량 검증은 유지한다.

검증은 가짜 계좌·전송·조회·실시간 이벤트를 사용한다. 매수 조건·종목 발굴 알고리즘·현재 잔고 수량 선택·장 운영시간을 변경하지 않았다. 실제 Indi 취소·부분체결·재시작 경로의 종단 검증은 미실행이며 이 작업의 실제 금융 API 호출은0회다.
