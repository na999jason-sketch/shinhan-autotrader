# 매수 진입 전략 변경 — 2.2.17

2.2.16의 정상 주문·손절·미체결 관리에 매수 진입 조건만 추가한다. 실주문 중지 방식·시장 운영시간·기존 보유의 손절/익절/추적손절·보유수량 선택·주문 전 계좌 검증·가능금액·미체결120초 정책·재시도/복구는 변경하지 않는다.

기존 조건은 완료 일봉의 단기선>장기선, 직전 고점 돌파, 당일 누적거래량>=직전 기간 일평균거래량×배수다. 전송 준비 중 가격의±3% 검사는 후보 포착 당시 가격을 기준으로 하므로, 최초 포착 자체가 돌파선보다 크게 높아진 경우를 거르지 못했다. 거래량은 당일 누적값이어서 돌파 직전의 새 체결이나 돌파 지속을 입증하지 않았다.

| 조건 | 2.2.16 | 2.2.17 기본값 |
| --- | --- | --- |
| 돌파선 대비 추격 상한 | 별도 상한 없음 | 현재가·실제 주문가 모두 돌파선 초과, 돌파선+2% 이하 |
| 돌파 지속 | 최신 시세에서 조건 재검사 | 실제 SC 관측으로60초 유지 |
| 최근 체결 유입 | 당일 누적거래량 조건 | 기존 누적량 조건에 더해 관측 중 거래량 증가 필요 |
| 시세 공백·돌파 이탈 | 새 시세에서 재판정 | 체결 간격15초 초과·돌파 이탈·과열이면 확인 재시작 |

추격 상한은0.01~10%, 확인 시간은30~300초로 저장한다. 기존 설정 XML에 필드가 없으면2%·60초를 기본값으로 사용한다. 기존 손절값·운용한도·미체결 대기시간을 덮어쓰지 않는다. 설정 저장의 기존 승인 해제 동작과 재시작 필요성은 유지한다.

`BreakoutConfirmationTracker`는 실제 `OnRealtimeQuote`에서만 관측을 받는다. 최초 관측과 최신 관측의 증권사 체결시각·수신UTC 경과가 모두 설정 시간을 채워야 한다. 매 관측은 기존 가격·완료봉·거래량·정규장·연속 수신 조건과 새 추격 상한을 충족해야 한다. 거래량이 증가하는 관측 사이의 수신·체결시각 간격은15초 이내여야 하며 마지막 관측도15초 이내여야 한다. 같은 시각·누적거래량의 재수신이나 시간만 흐른 콜백은 시간을 연장하지 않는다.

돌파선 이하·상한 초과·비정규장·연속 수신 미확인·시각/거래량 역행은 기존 확인을 제거한다. 종목·대상 거래일·사전분석 객체·진입 설정이 다르면 이전 확인을 사용할 수 없다. 연결 종료·종목 해제·분석 초기화·설정 저장에서도 관측을 제거한다. 관측 사이의 모든 가격이나 매수 주도 체결을 증명하는 장치는 아니다.

후보 표시·매수 준비·전송 전 검증에 같은 확인 상태를 사용한다. 계좌·가능금액 조회 뒤 최신 SC로 다시 검사하고 실제 주문가격도 추격 상한 이내인지 확인한다. 확인이 깨지면 아직 전송하지 않은 매수 준비만 해제하며 기존 주문을 취소하거나 손절을 중단하지 않는다. 가격이 같은 최신 체결이 들어와도 사전검증이 무한 반복되지 않도록 전략용 최신 시세와 기존 가능금액 조회가격 증거를 구분한다.

합성 검증은 과열 첫 포착(돌파선10,000/현재11,000), 정확한 상한 경계, 짧은 돌파 후 이탈, 재돌파의 새 확인, 정상60초 유지, 체결 공백, 캐시 시간 경과, 중복·역행·변조 시세, 설정 변경·거래일·종목 분리, 전송 직전 이탈/과열, 기존 잔고 갱신 후 확인 유지 등을 포함한다. 실제 폼 테스트도 필터를 끄지 않고 실제 SC 콜백 경로로 확인 시간을 채운다.

**이는 진입 조건과 주문 연결의 기능 검증이다. 실제 시세를 이용한 거래비용 포함 손익·최대낙폭 비교나 수익 최적화는 실행하지 않았다.**2%·60초는 초기 설정값이며 수익 개선을 입증한 수치가 아니다. 실제 계좌·금전 주문 API도 호출하지 않았다. 새 조건 때문에 매수 횟수가 줄거나 일부 상승을 놓칠 수 있다.
